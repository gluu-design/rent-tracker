# rent-tracker

A personal tracker of rent-stabilized 2BR+ apartments ($3k–$5k) in Greenpoint and Williamsburg, plus nearby areas.

**Live page:** https://gluu-design.github.io/rent-tracker/

- `index.html`: the tracker page.
- `data.json`: the listings, updated twice a day by an automated agent. Each listing has a confidence score and the evidence behind it: what the listing says, the building's stabilized-unit records, and whether the rent history follows the Rent Guidelines Board's renewal rates.

Scores are estimates, not legal determinations. Before signing, always ask for the rent-stabilized lease rider and the rent registered with the state (DHCR).
